# fc-quiz

國考題庫答題 App（建置中）。目前只有 **Phase 0 可行性測試頁**。

## Phase 0 在驗什麼

驗證這個架構成不成立：**PDF 只存在使用者自己的裝置上，網頁從連結準確跳到指定頁。**

這樣就能從 Notion 筆記或答題 App 點連結直接看 FC 原文那一頁，
而不必把有版權的 PDF 上傳到任何伺服器，也不必把書拆成幾百個小檔。

五項待驗：

| # | 項目 | 為什麼重要 |
|---|---|---|
| 1 | 存得下 | iOS 給網頁的儲存配額夠不夠放整本（最大一本 179 MB） |
| 2 | 跳得準 | 連結帶頁碼進來，要真的落在那一頁 |
| 3 | 重開還在 | 關掉 Safari 再開，資料不能消失 |
| 4 | 離線可用 | 沒網路時仍能開啟與跳頁 |
| 5 | 七天後還在 | iOS 會清掉「7 天未使用」網站的資料，這關最容易失敗 |

## 用法

用 **Safari** 開啟頁面，依序做 1 → 5。第 2 步選一本 FC 的 PDF 匯入
（建議挑最大的兒科當壓力測試）。

**建議先「加入主畫面」再從主畫面開啟**——iOS 對已加入主畫面的網頁給的儲存權限穩定得多。

## 已知事項

- 連結格式：`?page=158`，用 **PDF 頁次**，不是書上印的頁碼。
  兩者差距在整本書裡會變動（皮膚科從 +10 漂到 +2，因為夾了沒編號的章節隔頁與彩圖），
  所以不能用單一偏移值換算。書上印的頁碼由程式自動從頁尾讀出來，只拿來對照顯示。
- PDF 一律只存 IndexedDB。Service worker 只快取程式本身，**不快取 PDF**——
  否則 68 MB 的書會佔掉 136 MB。
- 本 repo 是公開的，**不會**放入任何 FC 的內容或掃描檔。
